# 转换工具箱

本地、离线、轻量的 Chrome 扩展。技术栈保持 TypeScript + Vite + 原生 DOM/textarea，转换在独立 Worker 中执行。仅有 `storage` 权限，没有站点权限、内容脚本或运行时网络依赖。

## 工作台与数据生命周期

六个模块各自保留本页内存中的输入、结果、所选操作、相关选项和状态。切换模块、重复点击当前模块、折叠导航、换主题不会清空内容。切换模块会取消仍在运行的任务；清空、输入或转换选项变更、导入成功也会使旧结果失效。编辑输入时采用“取消并清除旧结果，重新转换”的规则，复制和下载只使用匹配的成功结果。读取文件失败保留原输入，可以重复选择同一个文件重试；超限文件在读取前拒绝。

输入、输出和时间戳表单不写入 localStorage、扩展存储或网络。刷新、关闭工作台后临时转换数据清除，不做历史记录、跨会话恢复或云同步。仅外观、导航折叠、JSON 缩进及 Java 配置作为偏好保存；偏好写入失败不影响本页继续使用。

输入上限 **20 MiB UTF-8**，输出上限 **40 MiB UTF-8**，最大嵌套 **512 层**。可以取消 Worker；成功、失败、取消、切换模块和页面退出均会释放 Worker。多个模块保留的内容会占用相应内存，不设置历史副本；大文本关闭实时行列扫描，只提供按需查找和错误定位。

## 编辑、导入与下载

- `Ctrl/⌘ + Enter` 执行所选转换，`Ctrl/⌘ + Shift + C` 复制成功结果，输入区 `Ctrl/⌘ + F` 聚焦简单查找（区分大小写）。
- 输入区显示当前行列；可点击错误提示或“定位错误”，也可聚焦提示按 Enter/空格，定位并选中错误位置。定位来自结构化的字符偏移、行和列，不从中文提示中推断。
- “将结果作为输入”替换当前模块输入并清除旧输出，方便格式转换衔接；不跨模块自动覆盖输入。
- JSON / YAML 模块可导入 `.json`、`.yaml`、`.yml` 和 `.txt`。纯文本模块继续支持 JSON/TXT。
- 下载后缀和 MIME 由成功操作决定：JSON 为 `.json` / `application/json`，YAML 为 `.yaml` / `application/yaml`，Java 使用实际生成类名的 `.java` / `text/x-java-source`，反转义文本和查询字符串为 `.txt` / `text/plain`。MIME 均带 UTF-8。
- 外观和缩进下拉菜单可用方向键、Home/End、Enter/空格、Escape 和 Tab 操作。状态变化通过 live region 通知，控件具有标签和可见键盘焦点。

桌面采用紧凑标题栏和占用剩余高度的双栏编辑区，长文本在编辑器内滚动；行列信息位于输入区底部。输入卡片右上角“查找”可展开简单查找，Enter 查找下一个，Escape 或“关闭”收起并返回输入。浅色、深色和跟随系统主题共用布局；空白模块初始为“就绪”，无效执行后才提示错误。窄窗口编辑器上下排列，短窗口或浏览器放大时允许整页滚动，保证控件可达；时间戳按独立卡片布局。

## 数字与重复键规则

| 路径 | 保留约定 |
| --- | --- |
| JSON 格式化 / 压缩 | 保留原始数字 token、字符串及键的转义文本，只调整结构空白；拒绝重复对象键 |
| JSON ↔ YAML、YAML 格式化 | 数字不经过 `Number` 或普通对象的 `JSON.parse` 中转；大整数、小数、指数、负数及嵌套数字保持数值语义，当前实现沿用受支持的数字 token；数字字符串仍为字符串 |
| JSON → URL | 数字 token 精确编码为参数文本；URL 参数本身无数字/布尔/null 类型，反向转换全部为字符串，不能保证类型往返；数组转重复参数，空数组警告后跳过，拒绝嵌套集合 |
| URL → JSON | 同名参数依原顺序生成数组；`__proto__`、`constructor`、`toString` 为普通键 |
| JSON → Java | 整数依范围推断 Integer / Long / BigInteger，带小数或指数的数字使用 BigDecimal；字符串不据内容推断数字 |
| JSON 转义 / 反转义 | 处理文本与 JSON 字符串的编码，不对文本中的数字做类型转换 |

所有对象输入路径都拒绝重复键，包括 JSON 风格的 YAML 流式集合和 Unicode 转义后相同的键；URL 重复参数是明确支持的序列规则。跨格式转换不保留注释、缩进、对象键排版或字符串原始转义写法，不承诺任意 YAML “完全无损”。不要用普通 `JSON.parse()` 比较超安全整数范围的结果；测试使用保留数字文本的语义模型。

## JSON 兼容 YAML 安全子集

根节点支持对象、数组、字符串、布尔值、null 和 JSON 数字；空集合和嵌套空集合可读回。支持空格缩进的映射、序列、序列内映射、普通字符串、JSON 双引号字符串、YAML 单引号字符串（`''` 表示单引号）、行尾注释，以及**单行严格 JSON 写法**的流式集合。根节点还接受完整的多行严格 JSON；不因为它同时符合 JSON 就拒绝。

映射键必须为字符串；`true`、`false`、`null`、数字形式、空字符串和特殊字符键请加引号。生成器自动引用这些键及有歧义的字符串。引号内的 `& * ! # :` 是普通内容，普通文本中非语法位置的符号（如 `x *thing`、URL 内冒号）也可使用。

不支持锚点、别名、标签、合并键、复杂键、块文本、多文档、Tab 缩进、YAML 特有的隐式类型（如 yes/no、NaN/Infinity），以及非 JSON 写法的流式集合。集合内部不支持 YAML 注释、多行 YAML 流式写法或任意 YAML 转义；请使用块集合或严格 JSON。无值映射和空序列项按 null 处理。解析失败会尽可能提供对应位置；不会尝试执行任何 YAML 对象构造。

## Java 数据类

根对象和非空对象数组均可生成，数组对象字段按已有规则合并；类型冲突退化为 Object 并提示。对象数组按字段名追加 Item 命名，如 items → ItemsItem、二维 matrix → MatrixItemItem；中文字段可作为命名依据，中文诊断说明不会混入类名。根类、内部类名称避开实际使用的标准类型、生成注解名称和已有类名，访问器也会避开冲突，按确定的数字后缀或规范化名称调整并提示。下载名始终匹配最终根类名。

包名按每段 ASCII Java 标识符校验，拒绝关键字、空段和单独 `_`。保留 Jackson 字段映射及 Lombok 选项；启用对应选项的代码需要调用方项目提供 Jackson/Lombok。访问器命名同时避开 Lombok 的大小写冲突及 Unicode 首字母展开差异，发生重命名时给出提示。Node 测试会用本地 javac 编译不依赖这些库的生成结果，并通过 Java 反射确认标准类型未被内部类遮蔽，不只验证能否编译；另有固定版本真实 Lombok/Jackson 注解处理器测试，命令与 JAR 配置见根 README。

## 时间戳

- 输入单位可选自动、秒、毫秒。自动仅按 10 位秒、13 位毫秒识别（忽略负号）；其他长度、0、短秒数等会提示显式选择单位，避免猜测。
- 显式单位支持 0、合理范围负值；秒可含最多三位小数，毫秒必须为整数。范围为 JavaScript Date 的 ±8640000000000000 毫秒，不做静默截断或精度丢失。
- 可切换浏览器本地时间与 UTC；日期表单**使用所选时区**，切换时区保留表单文字并重新解释。结果保留毫秒，本地输出包含该日期的 UTC 偏移，UTC 输出 ISO 文本。
- 日期输入校验真实日期、时分秒及毫秒，不接受 Date 的溢出归一化。秒结果向下取整，毫秒结果完整保留。
- 本地时区夏令时跳过时段会报错，重复时段采用 JS Date 的较早时刻；需要明确无歧义的转换时可选择 UTC。不提供任意世界时区管理。
- 页面隐藏暂停时钟，回来只恢复当前时间刷新；不会重置日期、转换输入或再次绑定事件。

## 开发、发布和依赖

完整命令、Node 版本和版本升级方式见[根 README](../../README.md)。`build` 不再隐式打包，使用 `package` 或原有 `check` 入口生成 ZIP。当前扩展版本仍为 1.0.0，此次工作没有发布或创建标签。

新增 `fflate` 和 Prettier 均为开发依赖，分别解决跨平台 ZIP 生成和源码格式统一；构建不会把它们加入扩展，也不会增加运行时包体、权限或网络需求。测试、构建、包校验和性能测量互相分离，日常改动可以单独执行所需步骤。

源码边界：`core/*` 处理转换；`workbench/state.ts` 管理临时会话模型；`worker-client.ts` 负责 Worker 的完成/取消/释放；`text-tool.ts` 负责文本工具交互；`timestamp-tool.ts` 分离表单与时钟；`preferences.ts` 只处理偏好；`main.ts` 负责导航和外观。
