# 转换工具箱

离线运行的 Chrome 数据与时间转换扩展，包含 JSON 格式化、JSON 转义、URL 参数、Java 数据类、JSON / YAML 和时间戳六个模块。

[安装与功能概览](../../README.md) · [开发与打包](../../docs/development.md)

## 工作台使用

选择模块，粘贴或导入内容，再点击对应操作。结果可复制、下载，或通过「将结果作为输入」继续处理。

- 文本模块可导入 `.json`、`.txt`，JSON / YAML 模块还支持 `.yaml`、`.yml`；下载格式随操作自动匹配。
- 输入区支持区分大小写的文本查找；带位置信息的错误可点击提示或「定位错误」跳转。
- 切换模块保留各自的输入和已完成结果，并取消未完成任务；修改输入或转换选项后，需要重新转换。
- 临时转换数据仅存于页面内存，刷新或关闭后清除。外观、导航折叠、JSON 缩进和 Java 配置会作为偏好保存。

以下快捷键在文本模块的输入区生效：

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl / ⌘ + Enter` | 执行当前所选转换 |
| `Ctrl / ⌘ + Shift + C` | 复制成功结果 |
| `Ctrl / ⌘ + F` | 打开查找 |

## 转换规则

| 模块 | 需要了解的行为 |
| --- | --- |
| JSON 格式化 / 压缩 | 只调整结构空白，保留数字、字符串和键的原始转义写法；拒绝重复对象键 |
| JSON 转义 / 反转义 | 处理文本与 JSON 字符串之间的编码；反转义输入须包含外层双引号 |
| URL 参数 | JSON 转参数要求根节点为对象，数组生成重复参数，空数组提示后跳过，不支持嵌套集合；参数转 JSON 时值均为字符串，同名参数按顺序组成数组 |
| Java 数据类 | 接受根对象或非空对象数组，合并数组对象的字段；整数按范围使用 `Integer`、`Long`、`BigInteger`，小数及指数使用 `BigDecimal`，类型冲突使用 `Object` 并提示 |

Java 可配置根类名、包名、Jackson 字段映射与 Lombok。名称冲突会自动调整并提示，下载文件名与最终根类名一致。生成代码使用的 Jackson / Lombok 需由目标 Java 项目提供。

### YAML 支持范围

支持能映射到 JSON 的对象、数组、字符串、数字、布尔值和 null，包括空集合、空格缩进的映射与序列、单双引号字符串、行尾注释，以及单行严格 JSON 写法的流式集合。根节点也接受多行严格 JSON。

映射键必须是字符串，数字或布尔值形式的键需加引号。拒绝重复键、锚点、别名、标签、合并键、复杂键、块文本、多文档、Tab 缩进及 `yes/no`、`.nan/.inf` 等隐式类型；流式集合仅支持严格 JSON 写法。

JSON / YAML 转换保留数字精度与数据语义，数字字符串仍为字符串；不保留注释、原始排版或字符串转义写法。

### 时间戳与时区

- 自动模式仅识别 10 位秒、13 位毫秒（忽略负号）；`0`、短秒数等输入需手动选择单位。
- 显式单位支持零和范围内的负数；秒最多三位小数，毫秒须为整数，结果保留毫秒精度。
- 日期表单与结果均使用所选的本地时区或 UTC。切换时区会保留表单文字并重新解释。
- 无效日期和本地夏令时跳过时段会报错；夏令时重复时段取较早时刻。日期转秒向下取整，转毫秒完整保留。

## 处理限制

文本输入上限为 **20 MiB**，输出上限为 **40 MiB**，均按 UTF-8 字节计算；最大嵌套 **512 层**。大文本任务可取消，超限文件会在读取前拒绝。

时间戳范围为 JavaScript Date 支持的 **±8,640,000,000,000,000 毫秒**。时区支持浏览器本地时间与 UTC。
