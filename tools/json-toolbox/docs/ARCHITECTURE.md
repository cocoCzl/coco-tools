# JSON 工具箱架构说明

本文记录 V1 中不应在缺少背景的情况下随意改变的技术决策。产品功能与验收范围以 [PRD](./PRD-json-toolbox-v1.md) 为准。

## 原生轻量实现

工作台使用 TypeScript 与浏览器原生 HTML、CSS 和 API，不采用 React、Vue 等运行时框架，也不引入 Monaco、CodeMirror 或重量级组件库。

选择这一方式是为了控制安装包体积、启动速度和空闲内存。代价是复杂交互需要自行维护，未来切换框架会产生明显重写成本。

## 无损 JSON 标记处理

格式化和压缩只能改变字符串外部的非必要空白，不得改写数字、字符串转义、字段顺序或其他有效标记文本。

因此不能把 `JSON.parse` 后再序列化作为主处理路径。当前实现使用轻量解析逻辑完成严格语法校验、重复字段检测、错误定位和原始标记保留，以正确性优先于少量代码复杂度。

## 独立 JSON 工作台标签页

点击扩展工具栏图标后打开独立标签页，不使用狭小弹窗，也不向普通网页注入界面。

独立标签页为双栏编辑和 10–20 MB 数据处理提供足够空间，并使任务、输入和内存生命周期与普通网页隔离。代价是比弹窗多一次页面切换。

## 数据与权限边界

所有转换只在浏览器本地完成。扩展不读取网页内容、不申请站点访问或剪贴板读取权限，也不保存输入、输出和处理历史。Manifest 的 `storage` 权限仅用于记录已打开的工作台标签页。
